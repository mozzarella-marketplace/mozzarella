# Mozzarella

Mozzarella is a Hebrew-first learning platform where students solve a real-world problem for a simulated customer, moving from conversation to a written user story to a coded solution.

## Language

**Session**:
One student's ongoing engagement with a single customer problem, spanning the conversation, the user story, and the resulting solution.
_Avoid_: Project, engagement

**User Story**:
The student's written expression of the customer's need, saved as a single evolving draft per session rather than a version history.
_Avoid_: Requirement, spec, ticket
